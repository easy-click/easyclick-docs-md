# Features

* Supports Android 5.0 ~ 10.0
* Supports Root and non-Root, runs with accessibility services
* Supports randomizing all tap actions within a coordinate region
* Supports color-block and color find
* Supports control/node find — smarter than coordinate-only mode
* Supports OpenCV image matching with 95%+ recognition rate
