# Overview
- Accessibility mode requires the accessibility service to be enabled. If you activated the device from the computer, the service is enabled automatically!
- Note: On version 7.0 and above, all global functions are supported. On versions below 7.0 with accessibility, use only functions explicitly marked as 5.0+
- Accessibility mode has many API limits and cannot match all proxy mode capabilities
- See global functions for API usage
