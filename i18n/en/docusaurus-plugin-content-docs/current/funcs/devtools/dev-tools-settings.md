# Settings
 - Location: `IDEA menu bar - EasyClick Android - EasyClick Settings`
## Basic Settings
 - <img src='/androidimg/setting/basic_set.png' alt="basic_set.png" style={{zoom:'30%'}} />
 - `Debug version package name`: Used together with packaging a debug APK; enter the debug APK package name here to identify the debug app
 - `Local ADB file`: Select your own configured ADB executable; the default usually does not need to be changed
 - `Activator password and activator port`: Used with the activator; generally do not modify
 - The other options are deprecated
