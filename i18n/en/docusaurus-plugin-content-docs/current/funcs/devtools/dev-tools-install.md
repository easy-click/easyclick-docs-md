# Development Environment Setup
## Development Plugin Download
- **[Download the development plugin and Android activation tools together from the cloud drive]**
 - 123 Pan: https://www.123pan.com/s/6Hlmjv-QayIA.html
 - Baidu Netdisk: https://pan.baidu.com/s/124sTYQAZkedgfnTv3iFTZg Extraction code: 7bhy

## IDEA Development Tool
 - IDEA download: [IDEA official site](https://www.jetbrains.com.cn/idea/download/)
 - **Recommended: IDEA 2026.2 or later — no IDEA activation required; install the development plugin and use it directly**
 - Prefer the ZIP package (Windows x64 ZIP Archive (zip)); extract and run
 - After installation, open `bin/idea64.exe` to start

## Development Plugin Installation
 - Download from the cloud drive at: `Android Resources-EasyClick-Android-(version)-idea plugin.zip`
 - Download the latest EasyClick IDEA plugin and install it in IDEA. Installation guide: https://blog.csdn.net/qq_35246620/article/details/78289074
