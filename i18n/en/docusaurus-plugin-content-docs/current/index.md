# Android product highlights

:::info TL;DR
EasyClick Android is a **no-root** real-device automation platform: write EC scripts in IDEA, run via accessibility / BLE, and **package locally**; connect to the **cloud control system** for remote fleets. Suited for games, office work, and QA. Next: [First project](./getting-start).
:::

- Android automation scripting for games, office workflows, QA, and other repetitive tasks
- Compared with similar tools, EasyClick is stronger on IDE intelligence, API coverage, compatibility, and update cadence
- Software-only automation **and** BLE / hardware paths to reduce risk-control exposure
- ***Fully local standalone packaging — no upload to a cloud packager*** — safer than products that require cloud packaging

## EasyClick Android features

- Easy to program
- Rich APIs, image recognition, free OCR
- Can run standalone and ship separately
- Accessibility / non-root operation
- Smart IDE support
- More features in the docs below

## EasyClick Cloud Control

- Enterprise cloud platform tightly integrated with EasyClick — upload scripts and run without heavy integration work

### Cloud highlights

- Devices anywhere with internet access — push and run scripts remotely
- Scheduled and on-demand tasks
- Script data upload / fetch / update / delete
- Remote mirroring and remote phone control
- Low battery / offline alerts (DingTalk, email, etc.)
- Catch script exceptions remotely
- Bandwidth-saving mode
- Cloud onboarding: [Enterprise cloud intro](ecloud2/intro)
