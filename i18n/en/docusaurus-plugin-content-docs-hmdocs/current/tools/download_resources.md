## IntelliJ IDEA

:::tip
**IDEA 2026.2+ does not require activating IDEA** — install the EasyClick plugin and start. Prefer the latest build from JetBrains.
:::

- Download IDEA (files named `idea-xxx…`), or get it from the JetBrains site, then install the EasyClick plugin
