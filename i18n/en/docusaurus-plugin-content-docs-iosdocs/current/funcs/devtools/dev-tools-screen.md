# Screen
- Menu bar - EasyClick Development Tools - Node Capture
## Node Capture
- Click the node capture button to fetch current screen elements
- Click on the captured screen to select elements
- Copy node values in the node properties window
<br/>
<img src='/iosimg/node-1.jpg' width='300' />

## Screen Mirroring

 - Click the screen mirroring button to connect to the device screen for live preview and control
 - If the window is too small, click the three-dot button in the top-right to float the window
 <br/>

## Find Color and Find Image
- Click the node capture button to fetch current screen elements
- Right-click the image and select color/image mode
- Drag a rectangle over the desired region on the image
- Right-click and choose Pick Color, set the color block matrix size, click OK, then follow the prompts to generate code
- Find image: choose the find-image menu directly and save the image to the project's `res` folder
