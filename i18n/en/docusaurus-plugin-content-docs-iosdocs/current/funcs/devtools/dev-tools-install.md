# Development Environment Setup
- 123 Pan: https://www.123pan.com/s/6Hlmjv-QayIA.html
- QQ group download: 777164022
- Download the IDEA development tool (files starting with idea-xxx), or download from the IDEA website
- **Recommended: IDEA 2026.2 or later — no IDEA activation required; install the development plugin and use it directly**

- IDEA official download
 - Web: https://www.jetbrains.com/idea/download/
 - Historical versions (optional): https://www.jetbrains.com/idea/download/other.html
 - Commercial edition with JS IntelliSense: 2026.2 https://download.jetbrains.com/idea/idea-2026.2.win.zip

- After installation, open bin/idea64.exe to start
