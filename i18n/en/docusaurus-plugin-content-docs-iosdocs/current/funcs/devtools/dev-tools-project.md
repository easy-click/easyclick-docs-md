## Preview Project
- Menu `EasyClick Development Tools` - `Preview Project`
- Right-click the project or source file and choose `Preview Project`
- Preview renders the UI directly on the phone
<br/>
<img src='/iosimg/getstart-6.jpg' width='200'/>

## Run Project
- Menu `EasyClick Development Tools` - `Run Project`
- Right-click the project or source file and choose `Run Project`
- Run executes the script on the phone; all logs appear in `EasyClick Run Log`
<br/>
<img src='/iosimg/getstart-7.jpg' width='200'/>

## Package

- Menu `EasyClick Development Tools` - `Package Project`
- Right-click the project or source file and choose `Package Project`
- Packaging compiles source and outputs an APK; all logs appear in `EasyClick Run Log`
