## 1. Install the plugin

:::tip
- USB and standalone share **one** iOS IDEA plugin — install once
- Standalone features need plugin **4.6+**
- Plugin version may be much newer than the standalone runtime — that is normal; use the latest plugin
:::

- From [cloud downloads](/iostjdocs/tools/download_resources): **EC package → iOS resources → Dev plugin**<br/>
 <img src="/iostjimg/download-tj-idea.png" alt="download plugin" style={{zoom:'80%'}} />
- IDEA 2023 through latest supported
- **IDEA 2026.2+ does not require activating IDEA** — install the plugin and use it
- Walkthrough → [**Plugin install & overview**](https://www.laoleng.vip/docs/free-courses/ec-ios-tj#2%E5%BC%80%E5%8F%91%E6%8F%92%E4%BB%B6-%E5%AE%89%E8%A3%85%E4%B8%8E%E7%AE%80%E4%BB%8B)
- Restart IDEA after install
