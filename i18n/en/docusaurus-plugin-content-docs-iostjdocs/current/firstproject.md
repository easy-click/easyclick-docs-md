## 1. Install the plugin

- From the [cloud downloads](/iostjdocs/tools/download_resources): **EC package → iOS resources → Dev plugin** — file like `x.xx.x-iOS-EasyClick-USB+standalone-idea-plugin.zip`
- Steps are also in [Install IDE tools](/iostjdocs/tools/installdevtools)

## 2. Create a project

- iOS and Android both use a multi-module layout
- Open an empty folder (Open), e.g. `ttt`<br/>
 <img src="/iosimg/image-20220105095538754.png" alt="open folder" style={{zoom:'50%'}} />
- Right-click `ttt` → New Module<br/>
 <img src="/iosimg/image-20220105095622057.png" alt="new module" style={{zoom:'50%'}} />

- Choose **iOS — standalone project**, enter a name, Next<br/>
 <img src="/iostjimg/tj-module.png" alt="module type" style={{zoom:'50%'}} />
- Project structure after create<br/>
 <img src="/iostjimg/tj-module2.png" alt="project" style={{zoom:'50%'}} />

## 3. Connect a device

- Open the main app on the phone to see the connect address; in IDEA choose Device connect → Standalone device connect<br/>
 <img src="/iostjimg/tj-device-con1.png" alt="connect menu" style={{zoom:'50%'}} />
- Enter the device address → OK<br/>
 <img src="/iostjimg/tj-device-con2.png" alt="address" style={{zoom:'50%'}} />
- Connected<br/>
 <img src="/iostjimg/tj-device-con3.png" alt="connected" style={{zoom:'50%'}} />

## 4. Preview

- Select the standalone project → menu or right-click → Preview<br/>
 <img src="/iostjimg/fproject-pre.jpg" alt="preview" style={{zoom:'50%'}} />

## 5. Run

- Select the standalone project → menu or right-click → Run<br/>
 <img src="/iostjimg/tj-run-pro.png" alt="run" style={{zoom:'50%'}} />
