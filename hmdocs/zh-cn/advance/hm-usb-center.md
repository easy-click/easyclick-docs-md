# 新版中控使用指南

本章介绍 **鸿蒙Next USB 新版中控**（约 **3.0.0+**）的日常使用。安装与连机基础步骤见 [安装中控程序](/hmdocs/zh-cn/tools/installcenter)。

:::tip 软件下载
- 中控与投屏请到 [软件下载区](/community/download_area) 或 [教程资源](/hmdocs/zh-cn/tools/download_resources) 下载
- 网盘路径：**鸿蒙Next资源文件夹 → USB版本**，选择最新版本整包下载
:::

:::tip 版本说明
- **3.0.0+**：新版中控 UI、分组/脚本侧栏、批量重命名等
- **3.1.0+**：配套新版投屏 UI、OCR PPOCR-v6
- **3.2.0+**：蓝牙 HID 设置、脚本 `bleEvent`、投屏 BLE 手势
:::

## 启动与登录

1. 解压中控到**英文路径**（勿含中文、空格）
2. Windows 下双击 **`新中控.exe`** 启动（请从该入口进入，不要单独双击投屏程序）
3. 等待启动完成，进入 **智控管理**；未登录会弹出登录框，可注册后登录
4. 底部状态栏可查看运行状态、在线设备数等

若启动失败：确认路径合法、端口未被占用；可在启动页点 **重启中控** / **刷新状态**。

## 界面概览

顶栏四个入口：

| 入口 | 说明 |
|------|------|
| **智控管理** | 设备列表、脚本、分组、自动化（主工作区） |
| **定时任务** | 按天/间隔定时跑脚本 |
| **中控设置** | 基础配置、云控配置 |
| **授权中心** | 登录、USB 设备授权 / 投屏授权 |

智控管理布局大致为：左侧 **分组 + 脚本**，中间 **搜索 + 设备表格**，顶部 **常用 / 设备** 工具栏。

## 连接设备

### USB

1. 手机开启开发者模式与 **USB 调试**
2. 数据线连接电脑，信任本机调试
3. 中控设备列表出现设备后即可操作

详见 [安装中控程序 - 链接手机](/hmdocs/zh-cn/tools/installcenter#链接手机)。

### 无线调试

1. 建议先 USB 连接，点工具栏 **开启无线调试**（避免手机端端口随机）
2. 拔掉数据线后，点 **扫描无线设备**，填入 IP 与端口并扫描
3. 也可在手机开发者选项中查看无线调试地址后手动扫描

## 智控管理常用操作

### 工具栏 · 常用

| 按钮 | 说明 |
|------|------|
| **执行脚本** | 对勾选设备执行当前脚本（`.iec` / `.js`） |
| **停止脚本** | 停止选中设备上的脚本 |
| **开启自动化** | 启动自动化服务（列表「服务状态」变为是） |
| **停止自动化** | 关闭自动化服务 |

也可将 `.iec` 文件拖入窗口运行。

### 工具栏 · 设备

| 按钮 | 说明 |
|------|------|
| **新增分组** | 创建设备分组 |
| **集控投屏** | 选择 **全新界面**（推荐）或 **经典界面** 打开投屏 |
| **扫描无线设备** | 扫描无线调试设备 |
| **回收内存** | 触发中控内存回收 |
| **查看实时日志** | 需先选中设备 |

### 搜索与快捷键

- 搜索支持：设备 ID / 序列号 / 别名
- **全选设备** / **取消全选**、**列显示** 可自定义表格列
- **UI参数设置(新版)**：独立 UI 参数窗口
- 设备列表聚焦时：`Ctrl/Cmd+A` 全选；`Ctrl/Cmd+S` 全选并开启自动化；`Ctrl/Cmd+T` 停止自动化

### 左侧分组与脚本

- **分组**：筛选设备；右键可新增 / 删除 / 重命名 / 排序 / 刷新
- **脚本**：单击选中，**双击**执行；右键可执行、刷新、打开脚本目录

## 设备右键菜单

选中一台或多台设备后右键：

### 脚本与自动化

- 执行脚本 / 停止脚本
- **暂停/继续脚本** → 暂停执行、继续执行
- **自动化管理** → 开启自动化、关闭自动化

### USB HID 控制

- 一键开启 USB HID、激活 / 重置 USB HID
- USB 转网络连接、关闭 / 开启 USB 调试  

脚本侧对应 [USB HID 事件](/hmdocs/zh-cn/funcs/hid-event-api)。

### 蓝牙 HID 设置（3.2.0+）

- 绑定 / 解绑蓝牙 BLE、测试蓝牙 BLE、测试键盘按键
- 设置 WiFi（配网）、扫描开发板 IP、找蓝牙 / 找手机  

完整步骤见 [蓝牙 BLE 教程](/hmdocs/zh-cn/advance/hm-usb-ble)。

### 链接与设备

- 闪断 USB、开启 / 断开无线调试
- 重启设备、清除离线设备（谨慎）
- 设置分组 / 取消分组、设置别名
- 复制设备 ID / 序列号 / 全部信息
- 查看授权信息（跳转授权中心）

## 中控设置

### 基础配置

- 手机连接后是否自动开启自动化
- 是否启动 OpenCV、脚本启动随机延迟、内存回收间隔
- 切换分组是否默认全选设备
- 数据存储路径

### 云控配置

- 云控地址、设备编号字段（序列号 / 别名）、心跳间隔  
修改后点 **保存**。

## 授权中心

1. 登录账号（或注册）
2. 筛选已连接 / 未连接设备
3. **批量授权 / 换绑**：区分 **USB 设备授权**（跑脚本）与 **USB 投屏授权**（投屏操作）
4. 单设备右键也可新增 / 换绑 / 转让授权

也可在官网后台绑定后，在授权中心 **刷新**。

## 定时任务

1. 进入 **定时任务**
2. **新增任务**：选择每天 / 间隔分钟 / 间隔秒钟，指定分组或设备与脚本
3. **开启任务** / **暂停任务** 控制是否调度

## 打开投屏

新版投屏由 **新中控** 进入，无需单独启动投屏程序：

1. 确认已双击 **`新中控.exe`** 并完成登录，设备已连接；需要时先 **开启自动化**
2. 顶部工具栏点 **集控投屏**
3. 选择 **全新界面**（推荐，对应新版投屏客户端）
4. 按 [新版投屏使用指南](/hmdocs/zh-cn/advance/hm-usb-screen) 继续操作

## 快速上手清单

1. 双击 **`新中控.exe`** → 等待就绪 → 登录  
2. USB 连接手机 → 列表出现设备  
3. （可选）分组、设置别名、完成授权  
4. **开启自动化** → 服务状态为「是」  
5. 执行脚本，或 **集控投屏 → 全新界面**  
6. （可选）3.2.0+ 绑定蓝牙 BLE 后用于 HID 点击
