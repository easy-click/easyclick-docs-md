# 新版投屏使用指南

本章介绍 **鸿蒙Next USB 新版投屏**（约 **3.1.0+**）的操作方式。请先完成中控安装与连机，见 [新版中控使用指南](/hmdocs/advance/hm-usb-center)。

:::tip 软件下载
- 投屏随中控整包提供，请到 [软件下载区](/community/download_area) 或 [教程资源](/hmdocs/tools/download_resources) 下载
- 网盘路径：**鸿蒙Next资源文件夹 → USB版本**，选择最新版本
- 使用时双击 **`新中控.exe`**，再通过 **集控投屏 → 全新界面** 进入新版投屏
:::

:::tip 版本说明
- **3.1.0+**：新版投屏 UI、OCR PPOCR-v6
- **3.2.0+**：投屏场景「USB + 蓝牙 HID」、蓝牙手势与连板设置
:::

## 如何进入

新版投屏从 **新中控** 进入，请勿单独双击投屏程序：

1. 解压目录中双击 **`新中控.exe`**，等待启动并登录（见 [新版中控使用指南](/hmdocs/advance/hm-usb-center)）
2. 确认中控已正常启动（状态栏可看）
3. 顶部工具栏点 **集控投屏**
4. 在对话框中选择 **全新界面**（推荐），确定后打开投屏客户端

首次进入可出现新手引导：欢迎 → 选择白天/黑夜主题 → 开始使用。

## 界面概览

| 区域 | 说明 |
|------|------|
| **左侧栏** | 「工作台 / 更多」；顶部有全选、同步操作、开始/停止投屏 |
| **小屏网格** | 各设备缩略图；可勾选、框选、右键菜单 |
| **主控区** | 当前主控设备大屏；可嵌入侧栏或独立/浮动窗口 |
| **系统设置** | 输入、鼠标、OCR、投屏场景、主题等 |

## 投屏前准备

1. 手机已通过 USB（或无线调试）连上中控  
2. 在中控对目标设备 **开启自动化**，服务状态为「是」  
3. （跑脚本/投屏）完成对应 **USB 设备授权 / USB 投屏授权**  
4. 需要 BLE 手势时：中控先 [绑定蓝牙 BLE](/hmdocs/advance/hm-usb-ble)，手机已配对开发板  

## 投屏场景（系统设置 → 投屏设置）

推荐用场景卡片一键配置：

| 场景 | 手势方式 | 输入建议 | 适用 |
|------|----------|----------|------|
| **USB + 自动化服务** | **代理** | 系统默认 | 常规投屏点击/滑动 |
| **USB + 蓝牙 HID**（3.2.0+） | **蓝牙 HID** | 跟随 HID | 手势走 ESP32 板 |
| **自定义** | 手动选 | 手动选 | 高级参数自配 |

高级参数（展开）：

- **手势执行方式**：代理 / 蓝牙 HID（仅影响点击与滑动；键盘在「内容输入」）
- **蓝牙连板方式**：串口 / 网络（开发板需已配网）

## 开始投屏

1. 在系统设置确认场景（默认可用 **USB + 自动化服务**）  
2. 左侧勾选要投屏的设备（或 **全选设备**）  
3. 点 **开始投屏**；也可在小屏右键 → **投屏相关 → 开始投屏**  
4. 数秒后小屏出现画面；点 **停止投屏** 结束  

小屏右键还可：**投屏设置**、**横屏 / 竖屏**。

## 主控与同步操作

1. 在某一小屏右键 → **设为主控**（主控可 **取消主控**）  
2. 主控大屏上用鼠标操作手机  
3. 侧栏打开 **同步操作** 后，主控操作会同步到已勾选设备  
4. 主控标题栏 **控 / 鼠 / 键**：分别控制是否同步操作总开关、鼠标、键盘  

### 主控形态（侧栏 → 更多）

- **浮动窗口**：页内浮动 / **独立窗口**  
- **页面嵌入**：嵌入左侧 / 嵌入右侧  

## 常用操作

### 打字输入

1. **系统设置 → 内容输入**  
2. **输入法设置**：系统默认（代理输入）或 **跟随 HID**（BLE 键盘场景）  
3. 可配置打字模式、回车发送、输入框换行  
4. 主控区输入框可向主控设备发文字（中文建议系统默认 + 自动化）

### 上传图片 / 视频

- 侧栏工作台常用工具，或小屏右键 → **图片视频 → 传图片 / 传视频**  
- 支持按设备选择文件夹批量上传  

### 打开应用 / URL

- 小屏右键 → **更多功能 → 打开应用 / 打开 URL**  
- 或工作台对应入口  

### OCR 识字（3.1.0+）

1. **系统设置 → OCR**：选择引擎（可用 **PPOCR-v6**）  
2. 可选「识别后释放资源」  
3. 小屏右键 **识别屏幕文字**，或主控工具条 OCR  

### 话术 / 多设备回复

- 侧栏 **更多 → 回复**：话术回复、多设备回复  
- 多选小屏后右键也可进多设备话术  

### 系统控制

侧栏 **更多 → 系统控制** 或小屏右键「更多功能」：

- 杀死进程（全部 / 指定清理）、清理活跃  
- 锁屏 / 解锁、音量 ±、闪断 USB、重启设备  

多数高级操作需已登录。

## 小屏右键菜单摘要

| 分类 | 功能 |
|------|------|
| 投屏相关 | 开始/停止投屏、投屏设置、横屏/竖屏 |
| 主控 | 设为主控 / 取消主控 |
| 分组与命名 | 设置分组、重新命名 |
| 图片视频 | 传图片、传视频 |
| 识别 | 识别屏幕文字 |
| 蓝牙 | **蓝牙HID设置**（绑定/测试等，3.2.0+） |
| 更多 | 打开应用/URL、清理、锁屏解锁、重启、闪断 USB |

框选多个小屏后右键为批量菜单（含多设备话术）；需在系统设置中开启 **拖动选择小屏幕**。

## 侧栏工作台其他

- **设备分组**：筛选小屏；右键分组管理 / 批量分组 / 排序 / 刷新  
- **常用工具**：可自定义排序；含传图传视频、尺寸、横竖屏、滑动、HDC 设备、授权查询、系统设置等  
- **分辨率/方向**：投屏设置、小屏/主屏尺寸、小屏/主屏横竖屏  

开启 **分组切换节省流量** 可减少隐藏分组设备拉流。

## 系统设置其他 Tab

| Tab | 要点 |
|-----|------|
| **鼠标操作** | 滚轮、滑动模式（普通/多点触摸）、拖动选择小屏、同步随机延迟 |
| **其他配置** | 主题、启动默认主控、自动投屏、工具栏位置、小屏工具栏显示、USB 省流 |

## 蓝牙 HID 投屏简要流程（3.2.0+）

1. 中控完成 [蓝牙绑定与测试](/hmdocs/advance/hm-usb-ble)  
2. 投屏 **系统设置 → 投屏设置** 选 **USB + 蓝牙 HID**  
3. 内容输入建议选 **跟随 HID**；连板选串口或网络  
4. 开始投屏后，在主控/小屏上点击滑动即走 BLE  
5. 异常时小屏右键打开 **蓝牙HID设置** 复查绑定与串口  

## 快速上手清单

1. 双击 **`新中控.exe`** → 就绪后 **集控投屏 → 全新界面**  
2. 确认场景为 **USB + 自动化服务**（或按需 BLE）  
3. 勾选设备 → **开始投屏**  
4. 设主控 → 打开 **同步操作**（群控时）  
5. 按需使用传图、OCR、话术、系统控制  

## 常见问题

- **启动页提示需先启动服务**：请先双击 **`新中控.exe`** 并等待启动完成，再从中控 **集控投屏** 进入  
- **有画面点不动**：检查是否已开启自动化；BLE 场景检查绑定与手机配对  
- **同步无效**：确认侧栏 **同步操作** 已开，且目标小屏已勾选；主控栏 **控/鼠/键** 按需打开
