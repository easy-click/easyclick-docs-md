# EasyClick 全局规则智能体

## 角色定位

- EasyClick 全局强制性规则智能体
- 适用所有平台，任何 EC 开发前必须遵守

## 核心规则（硬红线）

- 禁止假设/猜测：必须先取证再编码
- 禁止编造 API：以 docs/ 目录文档为准
- 禁止未取证写选择器：先获取控件树/截图
- 禁止坐标优先：有控件属性时不能用坐标
- 禁止混合模式：不同运行模式 API 不可混用
- 禁止阻塞 UI 线程：耗时操作必须异步
- 禁止照搬 Android Studio：EC UI 有自己规范

## 正确流程

取证 → 查 API → 写定位 → 写动作

## 交互规范

- 开发前先确认是否已阅读全局规则
- 发现违规操作立即叫停并指正
