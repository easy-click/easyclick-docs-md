# 脱机激活器使用教程

## 概述

脱机激活器是一个独立的桌面客户端，用于为 iOS 设备批量准备自动化运行环境。它把原来需要在多个界面来回切换的操作（配对证书生成、镜像刷入、WiFi 调试、自激活环境就绪）整合到一个界面完成。

**适合人群**：运维人员、代挂服务商、需要批量管理多台 iPhone 自动化环境的用户。不需要写代码。

## 打开激活器

1. 启动 EasyClick 中控程序（ioscenter.exe）
2. 在顶部工具栏点击 **脱机激活器**
3. 在弹出的对话框中，选择 **全新界面**（推荐），然后点击确定
4. 稍等片刻，激活器窗口将打开

## 界面布局

打开后你会看到：

| 区域 | 说明 |
|------|------|
| 顶部统计栏 | 显示设备总数、已选设备数 |
| 工具栏 | 连接操作（USB 链接/WiFi 调试）、环境操作（刷入镜像/启动自动化服务）、自激活操作（批量自激活按钮组） |
| BundleId 配置区 | 设置主程序与代理程序的包名 |
| 设备列表 | 显示所有已连接设备，支持多选、排序、筛选 |
| 授权信息列 | 显示每台设备的授权到期状态 |

## 快速上手

按以下步骤操作，即可完成设备自动化环境的准备：

### 第一步：连接设备

1. 使用 **USB 数据线** 将 iPhone 连接到电脑
2. 确保爱思助手已安装并能正常识别设备
3. 在激活器中，点击工具栏的 **刷新设备** 按钮
4. 设备列表中应出现你连接的手机，连接方式显示为 USB

### 第二步：配置 BundleId

BundleId 是手机 App 的包名标识，激活器需要知道你的主程序包名才能工作。

1. 找到界面中的 **BundleId 配置** 卡片
2. 在 **主程序 BundleId** 输入框中，填写你的主程序包名（必填）
   - 例如：`com.example.automation`
   - 多个包名可以用英文逗号分隔：`com.app1,com.app2`
3. 在 **代理程序 BundleId** 输入框中，填写代理程序的包名（如需使用「启动自动化服务」功能则为必填）
4. 点击 **保存配置** 按钮

:::tip
如果不知道包名，可以在爱思助手「应用与游戏」中右键你的 App，选择「复制标识」获取。
:::

### 第三步：刷入开发者镜像

开发者镜像是手机与电脑通信的桥梁，需提前放置好对应版本的镜像文件。

1. 选中设备列表中的设备（可多选）
2. 点击工具栏 **环境 → 刷入镜像**
3. 观察设备列表中「镜像」列变为绿色 ✓，表示刷入成功
4. 如果刷入失败，检查：
   - 镜像文件是否已放入正确的目录
   - 手机是否已解锁并信任了电脑

### 第四步：初始化设备

初始化会将设备 ID 写入手机，建立设备与主程序的绑定关系。

1. 确保主程序已在手机上安装并处于前台
2. 在设备列表勾选需要初始化的设备
3. 点击工具栏 **自激活 → 批量操作 → 批量初始化**
4. 等待「消息」列显示 **成功**，如有失败请参考[常见问题](#常见问题)

### 第五步：开启 WiFi 调试（可选）

如果后续需要通过 WiFi 连接设备（不用 USB 线），需要先开启 WiFi 调试。

1. 选中设备
2. 点击工具栏 **WiFi 调试 → 开启 WiFi 调试**
3. 成功后，「调试地址」列会显示设备的 IP 地址

## 批量操作

激活器支持选中多台设备后执行批量操作，大幅提升效率：

| 操作 | 说明 |
|------|------|
| 批量初始化 | 对多台设备同时执行初始化 |
| 扫描设备 IP 地址 | 扫描局域网内所有已初始化设备的 WiFi IP |
| 批量生成配对文件 | 批量生成设备与电脑的信任配对证书 |
| 批量推送配对文件 | 将配对证书推送到手机 |
| 批量推送镜像文件 | 将开发者镜像推送到手机 |
| 一键完成自激活环境 | 自动打开 WiFi、生成配对、推送镜像和配对文件 |
| 自激活测试 | 验证自激活环境是否准备就绪（支持内部/外部 VPN） |

操作步骤：

1. 在设备列表中勾选需要操作的设备（可全选）
2. 点击工具栏 **自激活 → 批量操作**
3. 从下拉菜单中选择需要的操作
4. 确认弹出的提示对话框
5. 观察设备列表中「消息」列的结果

## 单设备操作

在设备列表中右键某行设备，或在每行末尾的「操作」按钮中，可以进行以下操作：

| 操作 | 说明 |
|------|------|
| 初始化 | 对该设备单独执行初始化 |
| 刷入镜像 | 对该设备单独刷入开发者镜像 |
| 一键自激活 | 自动执行 WiFi 开启、配对生成、文件推送全流程 |
| 自激活测试 | 测试该设备的自激活功能是否正常 |
| 重启 | 重启该设备 |
| 查看配对证书 | 查看和编辑该设备的配对证书内容 |
| 复制设备 ID / ECID | 一键复制到剪贴板 |

## 授权管理

:::tip
激活器左侧区域会显示该设备**授权有效期的标记**。发起初始化等操作时，系统也会验证授权状态。若授权已到期，该设备对应的行会标记 **×**。
:::

- 授权绑定需在 **中控 - 授权中心** 完成
- 绑定完成后回到激活器，刷新设备列表即可看到最新状态
- 如需换绑或转让授权，请参考 [授权/换绑/转让方法](https://www.laoleng.vip/docs/tools/easyclick/ios-qk/qa/authorize)

## 常见问题

### 初始化提示「请先填写并保存主程序 BundleId」

点击 BundleId 配置区的 **设置 BundleId** 按钮，填写主程序包名后保存。没有 BundleId 配置，激活器无法向手机写入设备 ID。

### 「启动自动化服务」提示「请先填写并保存代理程序 BundleId」

启动自动化服务需要代理程序协助，请确保已在 BundleId 配置中填写了代理程序 BundleId。

### 配对文件生成失败

- 确保手机已设置密码（锁屏密码）
- 如果之前生成过，选择「批量生成配对文件」会覆盖旧的证书
- 手机上可能会弹出「信任此电脑」对话框，请点击信任

### 镜像刷入失败

- 确保开发者镜像文件已放入 `bridgebin\config\DeveloperDiskImage` 目录
- 可以尝试用爱思助手的「实时屏幕」功能触发一次镜像推送

### 自激活测试失败

- WiFi 调试状态必须为开启（工具栏 **WiFi 调试 → 开启 WiFi 调试**）
- 配对证书必须存在且已推送到手机
- 手机必须连接 WiFi 网络（移动网络不可用）
- 如果使用外部 VPN 模式，确保 LocalDevVpn 已安装

### 设备列表为空

- 检查 USB 数据线是否连接正常
- 确保爱思助手已安装且能识别设备
- 点击工具栏的「刷新设备」按钮
- 尝试更换 USB 接口或数据线

### 确认弹窗无法换行

确认对话框中带有多行文本时（如「一键完成自激活环境」等提示）已支持自动换行显示。如果遇到排版问题，请将激活器更新到最新版本。
