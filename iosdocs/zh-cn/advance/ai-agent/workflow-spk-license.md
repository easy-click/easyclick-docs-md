# 工作流商业授权（`.spl`）

:::tip 已实现

AI 智能体客户端已支持：**签发授权**、**导入 / 更新授权**、**签发历史**（实施方本机）、**授权详情**（执行方查看）。

:::

## 解决什么问题

**商业授权（`.spl`）** 用于 **控制能否执行**：
- 实施方按 **工作流**、**手机 deviceId**、**有效期** 签发授权
- 客户导入 `.spk` 后，还须 **导入 / 更新 `.spl`**，试跑、任务、AI 运行才会放行
- 自写明文流程不受影响，**仅** 从 `.spk` 导入的只读流程（「S」标记）才需要商业授权。
- 工作流开发者售卖 **spk工作流** 使用商业授权给执行方

## 三种「授权」不要混

| 类型 | 谁管 | 作用                                  |
|------|------|-------------------------------------|
| **USB 设备授权** | EasyClick 平台 | 跑自动化点击、截图等（[环境与授权](./prerequisites)） |
| **`.spk` 工作流密码** | 实施方 | 导入流程包                           |
| **`.spl` 商业授权** | 实施方 | 允许 **哪条 工作流** 在 **哪些手机**、**什么时间段** 可执行 |

---

## 签发授权（实施方）

实施方在 **工作流编辑器** 中为已保存的 **工作流** 签发 `.spl` 文件，发给客户导入。

### 入口

1. 打开 **工作流编辑器**
2. 顶栏点击 **「签发授权」**

### 签发授权 Tab

1. **选择工作流**（必填）  
   - 在搜索框中按名称、ID、描述筛选 **根工作流**（不能选子流程，不能选已导入的 `spk_*`）  
   - 选中后显示 **packageId**；若提示尚未分配 packageId，请先在编辑器中 **保存一次** 该根工作流

2. **授权手机设备 ID**（必填，每行一个）  
   - 从中控设备列表复制 设备ID，粘贴到文本框  
   - 可点 **「复制设备ID」** 将当前列表复制到剪贴板（便于补发、核对）

3. **生效时间 / 到期时间**  
   - 默认：生效为当前时刻，**到期为一个月后**（可自行修改）

4. **授权密码**（必填，至少 8 位）  
   - 与客户交付 `.spl` 时使用；**建议与 `.spk` 导入密码分通道交付**（不同微信/电话/邮件）

5. **密码提示、客户备注**（可选）  
   - 备注仅保存在实施方本机签发历史，不会写入 `.spl` 文件

6. 点击 **「导出SPL授权」**，选择保存位置，得到 `.spl` 文件

7. 将 **`.spl` 文件** 与 **授权密码** 发给客户（**不要** 与 `.spk` 密码混在同一封可转发消息里）

:::info 续费 / 加手机

再次打开 **签发授权**，选择 **同一工作流**，修改 设备ID 或到期时间后重新导出 `.spl`。客户在原 `spk_*` 流程上 **更新授权** 即可，一般 **无需** 因升级 `.spk` 而重签。

:::

### 历史记录 Tab

每次签发成功后，本机会在数据目录保存 **签发历史**（明文备份），仅供实施方补发、续费、查账，**不会** 发给客户。

| 功能 | 说明 |
|------|------|
| **搜索** | 按工作流名称、授权编号、packageId、设备 ID 等过滤 |
| **授权编号** | 与 `.spl` 内 License 一致，便于与客户核对 |
| **复制设备ID** | 一键复制该次签发的全部 deviceId（换行分隔） |
| **复制授权密码** | 客户遗忘密码时快速重发 |
| **再签一份** | 预填工作流、手机、有效期等到「签发授权」Tab，改后重导 |
| **删除** | 仅删本机历史记录，不影响客户已导入的授权 |

## 使用授权（执行方）

执行方在导入 [`.spk`](./workflow-spk) 之后，为对应只读流程导入商业授权，才能试跑与批量运行。

### 前提

1. 已用实施方提供的 **`.spk` + 工作流导入密码** 完成导入，工作流库中出现带 **「S」** 标记的只读流程  
2. 已从中控获取要运行的手机的 **deviceId**，并确认实施方已将该 ID 写入 `.spl`

### 导入 / 更新授权

**方式一：工作流编辑器**

1. 在左侧工作流库找到 **「S」** 只读流程  
2. 悬停后点 **解锁图标**（导入 / 更新商业授权）  
3. 选择 `.spl` 文件，输入 **授权密码**（不是 `.spk` 导入密码）  
4. 成功后，流程旁显示授权状态：**未授权 / 已授权 / 已过期 / 未生效**

**方式二：AI 对话 · 工作流库**

1. 打开 **AI 智能体** → **AI 对话**  
2. 左侧工作流库中，对 **「S」** 流程点 **解锁图标**  
3. 同样选择 `.spl` 并输入 **授权密码**

:::warning 不能把 A 流程的 .spl 导入到 B 流程

`.spl` 需要与当前 `.spk` 包匹配

:::

### 查看授权详情（执行方）

在 **AI 对话 · 工作流库** 中，对 `spk_*` 流程点 **详情图标**（文档图标），打开 **SPK 详情** 对话框：

| Tab | 内容 |
|-----|------|
| **SPK 详情** | 名称、版本、步骤数、说明等 |
| **授权详情** | 授权状态、授权编号、包标识、生效 / 到期时间、授权设备列表；可 **复制全部设备 ID** |

工作流列表上的角标与上述状态一致，便于一眼判断是否可运行。

### 运行时的校验

对 `spk_*` 流程试跑、任务运行、AI 填参运行前，系统会校验：

1. 是否已导入 `.spl`  
2. **当前被选手机** 的 deviceId 是否在授权列表中  
3. 是否在 **生效时间 ~ 到期时间** 内

未通过时任务失败，并显示中文提示（如「设备未授权，不在商业授权列表中」）。

## 有效期
- 运行 `.spk` 流程前须 **联网**
- **断网或无法对时无法执行**，请恢复网络后重试

## 常见问题

**`.spk` 密码和 `.spl` 密码一样吗？**  
**不建议相同。** `.spk` 用于解密流程包；`.spl` 用于商业执行授权。请分通道交付。

**升级 `.spk` 后要不要重新签发 `.spl`？**  
一般 **不需要**。同一工作流，旧 `.spl` 仍可用于新包

**同一 `.spl` 能在多台电脑、多个 `spk_xxx` 上用吗？**  
可以。限制的是 **哪条 工作流 + 哪些手机 + 有效期**，不按 Agent 安装套数收费。

**授权密码忘了怎么办？**  
产品 **无法从 `.spl` 反查密码**。请联系实施方从 **签发历史** 中补发密码，或重新签发 `.spl`。

**提示「设备未授权，不在商业授权列表中」？**  
当前运行手机的 设备ID 不在 `.spl` 授权列表中，请联系实施方加手机或重签 `.spl`。

**提示「无法联网对时」？**  
检查网络后重试；`.spk` 商业授权执行前必须能联网。

**提示 USB 设备授权失败？**  
那是平台 [USB 设备授权](./prerequisites) 问题，与 `.spl` 无关，请分开处理。
