# 配置与数据目录

- 大部分设置都在 AI 智能体窗口里完成，**不必** 手动改文件。本节说明常用项；文件路径供备份、排查时参考。
- AI 设置 第一次会强制配置**数据存储目录**，就是为了避免数据丢失
## 设置对话框

路径：**AI 对话** 或 **工作流编辑器** → 工具栏 **「设置」**

| 配置项 | 说明 |
|--------|------|
| **数据存储目录** | 工作流、对话记录、模型配置等存哪 |
| **单任务最大设备数** | 一条任务最多 **同时** 跑几台手机（默认 100）；改后需 **重启 AI** |
| **切换标签自动保存工作流** | 编辑器里换标签时是否自动保存；改完 **立即生效** |

首次打开若提示数据目录未就绪，按提示进 **设置** 确认即可。

:::tip 改数据目录后

需要 **重启 AI**（重新点「启动 AI」或关闭再打开窗口）。**日志** 仍在 `aibin/log/`，不会跟着数据目录走。

:::

## 大模型配置

路径：工具栏 **「模型配置」**

### 可以保存多套

例如一套 DeepSeek 做日常，一套本地 Ollama 做测试。每套需填：

| 项 | 说明 |
|----|------|
| **名称** | 界面上显示的名字 |
| **接口地址** | 服务商提供的 API 地址 |
| **模型名称** | 如 `deepseek-chat` |
| **密钥** | API Key |

界面提供 **DeepSeek、OpenAI、Ollama** 等模板，选好再改密钥即可。

### 在哪里选用

- **AI 对话**：输入框下方选 **本会话** 用哪套
- **工作流 AI 面板**：生成流程时选哪套

保存后一般 **不用重启**，改密钥也会马上生效。

### 没配大模型时

对话只能输入 `list workflows`、`run …` 这类简单指令，见 [AI 对话](./ai-chat)。

## 视觉模型 VLM（进阶）

工作流 **「VLM·视觉定位」** 步骤，以及需要语义描述找元素时，使用 VLM 兜底。配置保存在数据目录下的 **`vlm_config.json`**。

:::note

目前 **没有单独的设置界面**，需要手动编辑该文件；后续版本可能会加图形界面。一般用户可先不用管，用 **节点抓取** 或 **图色找图** 即可。

:::

## OCR 引擎说明

工作流 **OCR** 步骤可选 **ocrType**（默认 `paddleOcrNcnnV5`）：

| ocrType | 说明 |
|---------|------|
| `paddleOcrNcnnV5` | 默认，本地 NCNN |
| `v5` | ONNX PaddleOCR v5 |
| `v4` | ONNX PaddleOCR v4 |
| `ocrLite` | OcrLite |

**按设备 + 引擎类型缓存**：同一台手机用过多种类型时，会分别占用内存；正式 **任务结束** 后释放，下次识别可能重新加载（首包略慢）。编辑器里 **OCR 预览** 为连续调试会保持引擎。

## 找图模板目录

若在 **流程配置** 里设置了 **工作目录**，建议在其下建立：

```text
{工作目录}/assets/templates/   ← 存放 PNG/JPG 小图
```

步骤里 `templatePath` 填相对路径，如 `assets/templates/btn_login.png`。详见 [图色找图](./image-match)。

## 数据目录里有什么（备份用）

默认根目录：`aibin/data/aiagent/`（或在设置里指定的路径）

| 文件夹 / 文件 | 存什么 |
|---------------|--------|
| `workflows/` | 所有工作流 |
| `runtime_data/` | 工作流运行产生的文件（默认 `runtime_data/{deviceId}/` 保存，`runtime_data/readdata/` 读取） |
| `llm_profiles.json` | 大模型配置 |
| `vlm_config.json` | 视觉模型 VLM 配置 |
| `chat/sessions/` | 对话历史 |
| `tasks.json` | 最近任务记录 |
| `external_registry.json` | 外部命令行 / HTTP / MCP 注册信息 |
| `audit/` | 部分任务产生的输出文件 |

**备份迁移**：复制整个数据目录即可；日志在 `aibin/log/`，可选复制。

工作流库里的 **打开文件夹** 可快速定位某条流程的文件。

## 高级：环境变量（可选）

仅当您熟悉命令行部署时才需要。可用来覆盖默认的大模型地址、密钥等，例如 `IOS_AI_LLM_API_KEY`。日常用界面 **模型配置** 即可。
