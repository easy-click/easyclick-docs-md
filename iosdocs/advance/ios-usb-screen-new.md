# 新界面操作指引

本章节介绍全新投屏界面的操作方式。请先在[主教程](./ios-usb-screen)中完成软件下载、签名 IPA、配置镜像等准备工作。

:::tip USB投屏使用指南视频教程
- 地址是 : https://space.bilibili.com/477518868/lists/8622038?type=season
- 用来讲解EasyClick iOS USB版本投屏的功能，比如同步操作投屏、输入文字、点击、上传视频和图片、操作手机剪切板、录制脚本等等
  :::

## 如何进入

1. 启动并登录中控
2. 在顶部工具栏点击 **集控投屏**
3. 在弹出对话框中选择 **全新界面**（推荐），点击确定
4. 等待投屏客户端窗口打开

## 界面概览

进入后你会看到以下区域：

| 区域 | 说明 |
|------|------|
| 侧边栏 | 左侧工作区和更多工具两个标签页 |
| 设备列表 | 显示所有已连接的设备，支持多选 |
| 主控窗口 | 中心区域，显示当前主控设备的屏幕 |
| 小屏幕 | 可拖拽的设备缩略图，右键可弹出操作菜单 |
| 系统设置 | 侧边栏或工具栏中可进入设置面板 |

## 启动自动化

:::tip
启动自动化需要回到中控界面操作，不在投屏客户端内进行。启动自动化前，请先在中控确认：
- 代理 IPA 已签名并安装到手机
- 开发者镜像已正确放置
- 在中控的系统设置中已填写代理 IPA 的 BundleId 前缀
- 投屏客户端的 IPA 包名设置中也同样填写一份（侧边栏或工具栏中找到「IPA包名」入口）
:::

1. 返回中控主界面，确认手机通过 USB 数据线连接到电脑，爱思助手能识别设备
2. 在中控的设备列表中，右键要操作的设备，选择 **开启自动化**
3. 等待片刻，设备列表中「服务状态」一栏变为蓝色 **是**，表示启动成功
4. 如果超过 1 分钟未成功，请右键选择 **测试自动化** 查看具体错误信息
5. 自动化启动成功后，再回到投屏客户端进行后续操作

:::tip
首次启动成功后，后续只需在投屏客户端中直接点击 **开始投屏** 即可，无需每次回到中控操作。自动化服务会在后台保持运行。
:::

## 投屏操作

1. 确保自动化服务已开启
2. 在系统设置中将投屏配置改为 **代理IPA** 方式
3. 在侧边栏或工具栏中点击 **开始投屏**
4. 等待几秒，主控窗口即可显示手机屏幕画面
5. 此时可通过鼠标直接操作手机界面：
   - 在系统设置中可调整滑动模式

## 常用操作

以下操作在新界面中的位置：

### 打字输入

- 在系统设置的 **内容输入设置 → 输入设置** 中，选择系统默认或自定义输入法
- 自定义输入法需要安装文件助手 IPA，具体点击设置面板中的 **键盘设置说明** 按钮

### 脚本录制

- 点击侧边栏的 **录制脚本** 按钮
- 新建脚本后点击 **开始录制**，在主控窗口上操作手机
- 录制完成后保存，即可选择执行
- 注意：必须在主控窗口上操作才能录制，运行脚本需要 USB 设备授权

### 上传图片 / 视频

- **iOS 15+**：使用工具栏中的 **上传视频** 或 **上传图片** 按钮；也可在小屏幕上右键 → 图片视频 进行操作
  - 支持 **选择文件夹** 批量上传，或 **选择图片/视频** 单个上传
- **iOS 15 以下**：需要使用 **文件助手功能**，需额外安装文件助手 IPA，在文件助手弹窗中按说明配置

### 剪贴板操作

#### 复制文字到手机
- 点击工具栏中的 **复制文字** 按钮
- iOS 15+ 需先将代理 IPA 置于前台（点击 **打开IPA** 按钮），再发送文字
- iOS 15 以下需使用文件助手功能

#### 读取手机剪贴板
- 在小屏幕上右键 → 剪贴板 → **读取剪贴板数据到电脑**
- iOS 15+ 需先将代理 IPA 置于前台

### 打开 URL

- iOS 15+：使用工具栏中的 **打开应用** 功能，先打开代理 IPA，再输入 BundleId 或 URL
- iOS 15 以下：需使用文件助手功能

### 其他

- 闪断 USB、重启设备、重启通信隧道等操作，可在设备右键菜单或工具栏中找到
- 自动化启动不成功时，可尝试闪断 USB；iOS 17+ 可尝试重启通信隧道
