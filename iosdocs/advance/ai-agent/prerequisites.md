# 环境与授权（必读）

:::warning 跑任何 AI 工作流前请先完成本节

**AI 对话里直接操作设备**、**工作流编辑器试跑**、**任务面板批量运行** 以及 **导入的 .spk 流程**，底层都会调用中控能力。  
若 **USB 设备授权** 或 **运行环境** 未就绪，会出现：授权检查失败、无法启动自动化、点击/截图无响应、BLE 步骤报错等。

请先按下面清单准备，再使用 [快速开始](./getting-started) 里的功能。

:::

## 一、购买并绑定 USB 设备授权

AI 智能体的自动化步骤（启动环境、点击滑动、跑工作流、IME 输入等）与 EC 脚本相同，必须使用 **USB 设备授权**。

:::caution 不要买错授权类型

| 授权类型 | 用途                       |
|----------|--------------------------|
| **USB 设备授权** | 跑脚本、**AI 工作流**、自动化服务等等功能 |
| **USB 投屏授权** | 投屏、鼠标操作界面、插入视频等等功能       |

AI 智能体需要的是 **USB 设备授权**。

:::

**操作步骤：**

1. 通过官方或代理商 **购买授权**
2. 手机 USB 连接中控后，打开 **授权中心 → 批量授权**（左侧填设备 ID，右侧填卡号）
3. 或在官网 [https://uc.ieasyclick.com](https://uc.ieasyclick.com) 进入 **我的 iOS 设备 → 批量绑定授权**，再回到中控 **授权中心 → 刷新授权**

## 二、配置运行环境

不同工作流步骤依赖不同环境。**保存流程前可以慢慢画，试跑或正式跑之前** 务必确认对应环境已配好。

### 方案 A：USB 自动化环境（代理 IPA / 脱机主程序）

**适用于** 大多数 UI 自动化，例如：

- 启动自动化环境（`ensure_auto_env`）
- 点击、滑动、输入文字
- 自动化截图 / OCR、界面节点抓取（`fetch_nodes`）
- IME 输入法相关步骤

**您需要完成：**

1. 在手机上 **安装并签名** 自动化服务 IPA（iOS 15+ 也可按投屏教程使用 **脱机版主程序 v7.2.0+** 作为自动化服务，功能更全）
2. 解压中控、配置 **开发者镜像**
3. 在中控填写 **代理 bundleID**，并成功 **开启自动化**（服务状态为 **是**）
4. 已完成上一节的 **USB 设备授权**

完整图文步骤见：[iOS USB 投屏教程 · 签名 ipa](/iosdocs/advance/ios-usb-screen#签名ipa)  
（同页还包含解压中控、刷镜像、启动自动化、投屏操作等，建议通读 **代理模式投屏** 章节）

:::info 部分步骤不需要自动化环境

例如 **无自动化截图/OCR**、部分 **打开 App**、**重置 USB** 等，可在未 `ensure_auto_env` 时使用。  
若整条流程只做这些操作，不必强行开启自动化；混用自动化步骤时则必须先启动环境。步骤说明见 [工作流步骤参考](./workflow-steps)。

:::

### 方案 B：蓝牙 BLE / OTG 环境

**适用于** 工作流中的 **`ble_*` 步骤**（蓝牙外设点击、滑动、按键等），或您在中控侧采用 **蓝牙 HID 投屏** 方案。

**您需要完成：**

1. 准备 BLE 模块/开发板，在中控设备右键 **蓝牙 HID 设置 → 绑定蓝牙 BLE**，并 **测试蓝牙 BLE** 通过
2. 按教程在 iPhone 上打开 **蓝牙、辅助功能** 等必要选项
3. 若使用 **OTG 模拟 HID**，需单独准备 OTG 模块、刷入对应固件并完成绑定

详细教程：

- [蓝牙 BLE 教程](/iosdocs/advance/ios-usb-ble) — 绑定、测试、手机端选项、WiFi 配网、快捷键等
- [OTG 教程](/iosdocs/advance/ios-usb-otg) — OTG HID 连接、开发板与快捷键配置

:::tip 两种环境可同时存在

同一台手机既可以配 **USB 自动化 IPA**，也可以配 **蓝牙外设**。  
流程里按步骤选用 `click_point`（自动化环境）或 `ble_click`（蓝牙环境）；**含有哪种步骤，就要先配好哪种环境**。

:::

## 三、跑工作流前自检

| 检查项 | 正常标准 |
|--------|----------|
| 设备在线 | 新中控设备列表中手机 **已连接** |
| USB 设备授权 | 授权中心已绑定，未过期 |
| 自动化环境（流程含 UI 自动化时） | 「开启自动化」成功，服务状态 **是** |
| 蓝牙 / OTG（流程含 `ble_*` 时） | 绑定并 **测试蓝牙 BLE** 通过 |
| 大模型（仅 AI 对话 / AI 写流程） | 已 [配置模型](./config)；**纯运行/试跑工作流不消耗 Token** |

仍失败 → [常见问题速查](./faq) · [常见问题](./troubleshooting)
