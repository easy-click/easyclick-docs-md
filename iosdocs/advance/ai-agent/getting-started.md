# 快速开始

:::warning 环境与授权（必读）

跑工作流、试跑、对话里操作设备前，请先完成 **[环境与授权](./prerequisites)**：

- 购买并绑定 **USB 设备授权**（不是投屏授权）
- 使用 UI 自动化步骤时：安装签名 IPA、开启自动化 → 见 [USB 投屏教程 · 签名 ipa](/iosdocs/advance/ios-usb-screen#签名ipa)
- 使用 `ble_*` 步骤时：配好蓝牙/OTG → 见 [蓝牙 BLE 教程](/iosdocs/advance/ios-usb-ble)、[OTG 教程](/iosdocs/advance/ios-usb-otg)

## 使用前准备

1. 打开 **新中控**（安装目录下的 **新中控.exe**）
2. 确认设备已在中控里 **正常连接**（与平时投屏、跑脚本一样）
3. 已完成 [环境与授权](./prerequisites) 中的 **USB 授权** 与 **运行环境** 配置

:::tip

日常只需：**打开新中控** → 点击 **「AI 智能体」**。其余后台程序由中控自动拉起，不用手动操作。

:::

## AI 智能体能帮您做什么

**不用写代码**，连上手机后，用 **中文说话** 或 **点几下按钮**，就能让多台 iPhone / iPad 自动干活。适合日常运维、批量测试、重复性操作多的场景。

### 开口就能做（AI 对话）

对着 AI 说人话，它会帮您在选定的手机上执行，例如：

- 「帮我在每台手机上 **打开微信**」
- 「对第一台做 **无自动化截图**」或「**无自动化 OCR** 看看有没有登录按钮」
- 「有哪些可以执行的自动化？」

信息不够时 AI 会 **追问**（比如没选设备会先问您要操作哪台），不会瞎猜。

### 一次做好，反复用（工作流）

把「打开 App → 点这里 → 等 3 秒 → 输入文字 → 截图保存」这类固定套路 **画成流程图**，以后：

- 左侧工作流库 **一键运行**
- **多台手机同时跑**，进度在任务面板里看
- 某一步需要 **人工验证码**？流程会自动暂停，您弄完点 **继续** 即可

:::tip 工作流运行不消耗 Token

**运行、试跑已保存的工作流** 走的是本地步骤引擎，**不调用对话大模型**，**不消耗 Token**，也 **不必配置或连接大模型 API**。

只有 **AI 对话**（用中文安排任务）和编辑器里 **让 AI 帮您生成/改流程** 才会用到对话大模型。流程画好后，日常批量跑任务 **零 Token 成本**。

若流程里包含 **「VLM·视觉定位」** 等步骤，仅该步会按 `vlm_config.json` 调用视觉模型，与对话大模型无关；未使用此类步骤时，整条流程均不联网调用大模型。

:::
### 不会画流程？让 AI 帮您写

在工作流编辑器里用中文描述需求，例如「先打开 Safari，再访问某网址，最后截图」，AI 可以 **帮您生成流程图**，您再试跑、微调、保存。

### 典型使用场景

| 场景 | 能做什么 |
|------|----------|
| **多台手机批量操作** | 一次选中 10 台、50 台，同一条流程一起跑 |
| **App 功能走查** | 无自动化/自动化截图、OCR 识文字、**模板/偏色找图**、VLM 视觉定位、自动点击滑动 |
| **登录 / 注册 / 下单** | 做成工作流，每天定时或按需批量执行 |
| **相册素材下发** | 从电脑文件夹 **导入图片、视频** 到设备相册 |
| **输入法场景** | 通过专用输入法步骤输入、粘贴、读剪贴板 |
| **连接异常恢复** | 流程里可加重置 USB、等待重连，减少人工拔插线 |

:::tip 和写脚本的区别

**AI 智能体**：在专用窗口里 **直接操作已连设备**，上手快，适合快速编排和批量任务。  
复杂业务逻辑仍可用 EC 脚本；两者可以 **配合使用**。

:::

## 三步上手

:::tip 界面长什么样？

可先浏览 [界面预览](./screenshots)（对话 / 工作流 / 任务面板截图与 30 秒路径图）。

:::

### 第 1 步：打开 AI 智能体

1. 启动 **新中控**
2. 点击 **「AI 智能体」**
3. 进入后默认是 **AI 对话** 页；若顶部提示未连接，点 **「启动 AI」**

### 第 2 步：配置大模型（建议）

要用 **中文对话** 驱动设备，需要先配好大模型：

1. 点击工具栏 **「模型配置」**
2. 点 **新增**，按您使用的服务商填写，例如 DeepSeek、OpenAI、本地 Ollama 等：
   - **名称**：随便起一个好记的，如「DeepSeek 主力」
   - **接口地址**、**模型名称**、**密钥**：按服务商文档填写
   - 界面里也有 **DeepSeek / OpenAI / Ollama** 等快捷模板，选后改密钥即可
3. **保存** 后，在对话页输入框下方选中刚配的配置

:::note 没配大模型也能用

未配置时，对话里只能输入简单指令，例如「列出工作流」「运行 xxx 工作流」。配置大模型后体验会好很多。

:::

### 第 3 步：选择设备

在页面 **左侧**：

- **设备**：勾选要操作的手机（可多选）
- **分组**：按中控里的投屏分组一次选多台

选好设备后，再跟 AI 说「在这几台手机上……」即可。

## 怎么知道已经准备好了

| 看哪里 | 正常时长什么样 |
|--------|----------------|
| 顶部连接状态 | 显示 **已连接** 或绿色提示 |
| 模型名称 | 工具栏能看到当前选用的模型 |
| 左侧设备 | 有在线设备，且已勾选 |
| 工作流库 | 能 **新建** 或看到已有流程 |

## 数据保存在哪（一般不用改）

默认情况下，工作流、对话记录、模型配置等都在安装目录下的 **`aibin/data/aiagent/`** 里。

若您在 **「设置」→ 数据存储目录** 里改了路径，上述内容会改存到您指定的文件夹；改完后需要 **重启 AI**（点「启动 AI」或重新打开窗口）。

**运行日志** 始终在 **`aibin/log/`**，不会随数据目录一起变。

:::tip

想备份：复制整个 `aibin/data/aiagent/` 文件夹即可保留工作流和配置。

:::
