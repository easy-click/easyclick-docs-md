# 外部集成（进阶）

:::info 适合谁

本节面向需要把 **自己的程序、HTTP 接口** 接进自动化流程的用户。日常只用 AI 对话和工作流，**可以跳过** 本章。

:::

AI 智能体可以把您信任的 **外部能力** 登记起来，供 **工作流步骤** 或 **AI 对话** 调用。

打开方式：工具栏 **「CLI/MCP 集成」**

## 能登记哪些类型

| 类型 | 典型用途 |
|------|----------|
| **命令行程序** | 跑本机 `.exe`、脚本，例如整理文件、调用自研工具 |
| **HTTP 接口** | 调 REST API，查数据、通知别的系统 |
| **MCP 服务** | 对接支持 MCP 协议的工具（进阶集成） |

登记并 **保存** 后，编辑器里添加对应步骤、对话里让 AI 调用时就能选到。

## 登记命令行程序

1. 点 **选择可执行文件**，选本机程序
2. 填 **名称**（系统会生成 ID，可改）
3. 可选：同目录放 **说明文档**（如 `SKILL.md`），方便 AI 理解怎么用
4. 保存

**工作流里**：添加 **「运行命令行」** 类步骤，选刚登记的程序，填参数。

**对话里**：可以说「用 xxx 工具列出某目录」，AI 会按登记信息构造命令（仅限已登记程序，更安全）。

:::warning 安全提示

命令行以 **中控所在电脑** 的权限运行，只登记 **您信任** 的程序。

:::

## 登记 HTTP 接口

1. 填 **名称**、**基础地址**（如 `https://api.example.com`）
2. 可选默认请求方式、请求头
3. 保存

**工作流里**：添加 **「调用 HTTP」** 步骤，选登记的接口或写完整 URL。

**对话里**：可临时探查接口；固定流程建议写进工作流。

## 登记 MCP 服务

MCP 用于对接支持该协议的外部工具（本地进程或远程 HTTP）。保存时可 **同步工具列表**，之后在工作流或对话里选择具体工具调用。

细节因服务商而异，按 MCP 提供方文档配置即可。

## 和「与 AI 结合辅助编程」里的 CLI 区别

[与 AI 结合辅助编程](../ios-usb-ai) 里的工具主要用于 **编译 EC 脚本**；这里的登记用于 **跑自动化时的外部程序**。两套 **互不影响**。若希望流程里调用 EC 编译器，需在本页 **单独登记** 该程序。
