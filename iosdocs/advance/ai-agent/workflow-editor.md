# 工作流编辑器

:::tip 试跑前请确认环境

运行或 **试跑** 工作流前，请先在 [环境与授权](./prerequisites) 中完成 **USB 设备授权** 与对应 **自动化 / 蓝牙环境**。否则常见步骤会直接失败。

:::

**工作流** 就是把「点哪里、等多久、打开哪个 App」等步骤保存成 **可反复运行** 的流程。点击顶部 **「工作流编辑」** 进入编辑器。

## 界面说明

- **左侧**：工作流库（树形，含主流程和子流程）
- **中间上方**：已打开的流程标签（可同时开多个）
- **中间下方**：**可视化流程图** 或 **文本模式**（进阶用户）
- **右侧**：选中步骤的参数、**变量池**、AI 辅助面板

## 工作流库（左侧）

- **根**：独立的主流程，可直接运行
- **子**：被主流程调用的子流程，缩进显示
- 点击名称 **打开编辑**；鼠标悬停可 **打开文件夹**、**删除**
- 左侧面板可 **收起**，画布更大
- **根** 流程可 **导出为 .spk 包**（见 [工作流 .spk](./workflow-spk)）；**「密」** 标记为导入的只读包

## 新建与保存

| 操作 | 怎么做 |
|------|--------|
| **新建** | 顶栏 **新建**，填名称 |
| **保存** | **保存** 按钮，或 **Ctrl+S**（Mac：**Cmd+S**） |
| **校验** | 保存前点 **校验**，检查有没有漏填、连错的线 |
| **排版** | 自动整理流程图布局 |

在 **设置** 里可开启 **切换标签时自动保存**。

步骤卡片右上角可切换 **简单 / 进阶** 模式：简单模式隐藏 JSON 与高级项，进阶模式显示完整配置。

## 两种编辑方式

| 模式 | 适合谁 |
|------|--------|
| **可视化** | 大多数人：拖拽节点、连线、点选步骤改参数 |
| **文本** | 熟悉配置文件的用户：直接改 JSON |

入门建议一直用 **可视化**。

## 流程图里有什么

- **方框（状态）**：一组按顺序执行的步骤
- **箭头**：上一步成功后去下一步；也可画 **失败**、**条件** 分支
- **菱形**：按条件走不同分支（例如「找到了就点，找不到就等待」）
- **子流程**：某一步改为调用另一个已保存的流程（**invoke**）

画布支持 **拖动、缩放**、**小地图**；**Ctrl+Z**（Mac：**Cmd+Z**）撤销；右键可复制、删除、在连线上 **插入步骤**。

执行试跑后，节点会 **绿/红/蓝高亮**，选中可看该步日志与输入输出。

## 变量：流程配置与变量池

对用户只需记住两类数据：

| 类型 | 含义 | 在哪配 |
|------|------|--------|
| **流程配置** | 流程开始前就有的默认值（包名、关键词等） | **流程配置** 对话框 |
| **步骤结果** | 某步跑完后留下的数据（截图、OCR、找图匹配等） | 步骤里的 **保存到变量** |

**变量池**（画布工具栏）集中查看上述变量：

- **设计** 视图：根据流程结构推断有哪些配置与步骤结果
- **运行** 视图：试跑完成后显示 **实际变量值**
- 点击变量可在画布 **高亮** 引用它的步骤
- 可选开启 **试跑变量流**，只看本次运行经过节点之间的数据连线

**调用子流程** 时，用 **勾选清单** 选择传入/带回的变量，无需手写 JSON（进阶模式仍可编辑）。

## 试跑（很重要）

改完流程建议先 **试跑**，不要直接上生产机：

1. 在工具栏选一台 **在线设备**
2. 点 **试跑** / **运行**（或 **从此步试运行** / **运行选中步骤**）
3. 画布上步骤会 **变色**：运行中、成功、失败一目了然
4. 可随时 **强制停止**

试跑会生成真实任务，详情见 [任务与监控](./tasks)。从任务面板点 **「工作流编排」** 可回到编辑器，并 **回放** 当时每一步的结果。

## AI 辅助写流程

右侧 **AI 面板**（需先 [配置大模型](./getting-started)）可以：

- 用中文描述整段自动化，让 AI **生成流程图**
- 勾选 **仅修改选中状态**，让 AI **局部改写** 部分节点
- 多轮对话慢慢改，直到满意

生成后仍建议 **校验** 并 **试跑** 一遍。

## 流程配置（全局设置）

点 **流程配置** 可设置：

| 项 | 用途 |
|----|------|
| **工作流默认 / 本流程启动** | 两类流程配置，控制试跑与运行时的覆盖规则 |
| **传入参数（试跑）** | 试跑时覆盖默认值的键值 |
| **工作目录** | **可选**。指定本机文件夹后，文件类步骤与 **找图模板** 优先用该目录；建议建 `assets/templates/` 存小图 |

**工作目录** 与 **相册导入** 用的 `folderPath` 不同：相册步骤需填本机绝对路径；`save_file` / `read_file` 未设工作目录时，会自动写到数据目录下的 `runtime_data/`，**不必** 先配工作目录。

## 编辑某类步骤时的预览

选好试跑设备后，部分步骤支持 **预览**：

| 步骤类型 | 预览能力 |
|----------|----------|
| **OCR** | 截屏并识别文字（默认无自动化截屏） |
| **找图 / 偏色找图** | **找图预览**：匹配框、框选搜索区域、裁剪保存模板 → 见 [图色找图](./image-match) |
| **节点抓取** | 看当前界面有哪些可点元素（需自动化环境） |
| **VLM 视觉定位** | 按中文描述在截图上标位置 |
| **坐标点击** | 在截图上选点 |
| **pick 数据提取** | 基于 **上次试跑** 的输入/输出快照预览 |

**截图** 与 **OCR** 各拆成 **无自动化**、**自动化** 两个独立步骤，与 [AI 对话](./ai-chat#截图与-ocr) 名称一致。

## 子工作流

- 添加 **调用子流程** 步骤，选择已有工作流 ID
- **双击** invoke 节点或右键 **进入子工作流** 可编辑子流程（画布内默认不展开子图）
- 配置 **传入参数**、**写回变量**、**成功记录（可选）**

## 打开流程文件位置

工作流库每项旁的 **文件夹图标** 会在电脑上打开该流程 **文件所在目录**，方便备份或拷贝。
