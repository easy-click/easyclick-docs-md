# 工作流包（`.spk`）

`.spk` 用于把做好的工作流 **打包** 发给其他人：对方可以 **运行 / 试跑**，但 **不能查看或修改** 流程细节，也不能另存为明文工作流。

## 谁做什么

| 角色 | 做什么                                          |
|------|----------------------------------------------|
| **实施方**（你） | 在编辑器里把明文工作流 **导出为 .spk**，设密码，发给客户            |
| **执行方**（客户） | 在编辑器里 **导入 .spk 包**，输入密码，得到带 **「S」** 标记的只读流程 |

## 导出（实施方）

1. 打开 **工作流编辑器**，在左侧库中找到 **根工作流**（不是子流程）
2. 鼠标悬停，点 **下载图标**，或按对话框提示操作
3. 对话框会显示 **导出闭包预览**：包含哪些子流程、模板图片会被打进包
4. 设置 **导出密码**（至少 8 位），可选填 **密码提示**（如「请联系张三索取密码」——**不是密码本身**）
5. 可选勾选 **导出 zip 包**：内含 `.spk` + `导入说明.txt`（说明里 **不含密码**）
6. 选择保存位置

导出成功后，请按对话框中的 **分发指引** 操作：

- **文件**（`.spk` 或 zip）与 **密码** 走 **不同渠道**（如网盘 + 微信/电话）
- **不要** 在同一封可转发的邮件里同时写密码和附件

本机会记录 **最近导出历史**（含本机备份的密码，仅当前 Agent 数据目录可读），方便客户遗忘密码时重发。

## 导入（执行方）

1. 顶栏点 **「导入 .spk」**，或在 AI 对话侧栏工作流库点 **上传图标**
2. 选择 **`.spk` 文件** 或 **导出 zip 包**（zip 会自动读取其中的 `.spk`）
3. 输入实施方提供的 **导入密码**
4. 若本机已安装 **同系列** 工作流（相同包或同根流程升级），可选择 **并列安装** 或 **覆盖已有**（覆盖保留原 `spk_xxx`，适合升级）
5. 导入成功后，左侧出现带 **「S」** 标记的只读工作流

导入只读流程后，还须按 **[工作流 .spl 授权](./workflow-spk-license)** 导入商业授权，才能试跑与任务运行。

## 导入后能做什么

| 可以 | 不可以 |
|------|--------|
| 试跑、任务运行 | 编辑、保存、改 JSON |
| 只读查看流程图 | 导出 .spk、另存明文 |
| AI 对话里选此流程填参运行 | 查看完整步骤参数与实施 prompt |

## 卸载 .spk 包

在工作流库中对 **「S」** 流程点 **删除**，确认 **卸载**。卸载后需重新导入 `.spk` 包才能再用。

## 常见问题

**密码忘了怎么办？**  
产品 **无法找回**。请联系实施方重新索取 `.spk` + 密码。

**同一个包能导入两次吗？**  
可以。每次导入可生成新的 `spk_xxx`（并列），或覆盖已有安装（升级）。

**子流程会单独出现在库里吗？**  
不会。子流程打在包内，仅根流程以 `spk_xxx` 出现在列表中。

**和明文工作流冲突吗？**  
不会。`spk_xxx` 与明文 id 命名空间隔离。

**实施方能否按设备和时间限制客户执行？**  
见 **[工作流 .spl 授权](./workflow-spk-license)**：实施方 **签发授权**，执行方 **导入授权**；绑定 workflow id + 手机 deviceId + 有效期。
