# 任务与监控

每次运行工作流（无论是 AI 安排的还是您手动点的 **运行** / **试跑**），都会生成一条 **任务**。一台或多台手机同时跑，也算 **同一个任务**。

## 任务从哪来

| 方式 | 说明 |
|------|------|
| **AI 对话** | 跟 AI 说「帮我执行……」，AI 安排好会自动开跑 |
| **工作流库 → 运行** | 对话页左侧卡片上点 **运行** |
| **编辑器试跑** | 工作流编辑器里选设备后点 **试跑** / **运行** |
| **定时任务** | [工作流定时任务](./workflow-schedule) 到点自动触发 |

## 打开任务面板

在 **AI 对话** 或 **工作流编辑器** 工具栏，点 **「任务面板」**。

弹窗里看列表，关窗后回到原页面。

## 任务列表里有什么

- 最近约 **100 条** 任务；正在跑的会 **自动刷新**
- 每条显示：**状态**、**来源**（AI 会话 / 工作流编辑器 / 定时任务等）、跑了 **几台设备**、成功/失败数量、时间
- 列表 **默认折叠**；点击一行展开设备明细
- 顶部还有 **并发概况**：最多能同时跑几台、当前跑了几台（与 **设置 → 单任务最大设备数** 有关）

### 任务状态（中文对照）

| 显示 | 含义 |
|------|------|
| 等待中 | 已创建，还没开始 |
| 运行中 | 至少有一台还在执行 |
| 已完成 | 全部成功 |
| 失败 | 全部或关键步骤失败 |
| 部分成功 | 有的成功、有的失败 |
| 已暂停 | 有人在等您手动操作后继续 |

## 点开一条任务

展开后能看到 **每一台设备** 单独的状态：

- 正在跑哪条 **工作流**
- 当前到 **哪一步**
- 若失败，**错误说明** 是什么

还可查看 **每一步的详细结果**（输入、输出、截图等），方便排查。

## 常用操作

| 按钮 | 什么时候用 |
|------|------------|
| **继续** | 流程里有「等人操作」的步骤，您在手机上弄完后，点这里接着跑 |
| **强制停止** | 任务卡住或想取消 |
| **工作流编排** | 跳转到编辑器，并 **回放** 这次执行过程 |
| **复制任务 ID** | 联系技术支持时提供 |

## 「等人操作」的步骤

有些流程会在某一步 **停下来**，等您在手机上完成验证码、手工确认等，然后再继续。例如：

1. 任务状态变成 **已暂停**
2. 您在设备上做完该做的
3. 回任务面板，点该设备的 **继续**

## 在编辑器里回放

从任务面板点 **「工作流编排」**，或在编辑器 **试跑** 时：

- 流程图上 **高亮** 已跑过的步骤
- 失败步骤会标 **原因**
- 可打开 **运行日志** 看详细记录

编辑器里还可 **从某一步重新试跑**、**只跑到某一步**、**运行选中的连续步骤**，方便调试。

正式任务跑 OCR 较多时，任务结束后该设备的 OCR 引擎会释放；下次同类任务首步 OCR 可能多等几秒，属正常现象。
