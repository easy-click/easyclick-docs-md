# 开发环境安装
- 123网盘：https://www.123pan.com/s/6Hlmjv-QayIA.html
- QQ群下载：777164022
- 下载idea开发工具，文件以idea-xxx开头的，也可以自行到idea官网下载
- **推荐下载 IDEA 2026.2 及以上版本：无需激活 IDEA，直接安装开发插件即可使用**

- IDEA官网下载地址
    - 网页地址：https://www.jetbrains.com/idea/download/
    - 历史版本（可选）：https://www.jetbrains.com/idea/download/other.html
        - 商业版本JS智能提示：2026.2 https://download.jetbrains.com/idea/idea-2026.2.win.zip
    
- 安装后，打开bin/idea64.exe文件开始运行
