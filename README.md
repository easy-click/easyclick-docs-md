# EasyClick Docs (Markdown only)

本仓库为 [EasyClick 官网文档站](https://ieasyclick.com) 的 **Markdown（仅 `.md`）镜像**，不含 MDX、React 页面与站点工程代码。

## 目录说明

| 目录 | 内容 |
|------|------|
| `docs/` | 安卓文档 |
| `iosdocs/` | iOS 文档 |
| `iostjdocs/` | iOS 脱机相关文档 |
| `hmdocs/` | 鸿蒙 Next 文档 |
| `community/` | 社区 / 选型等 |
| `blog/` | 博客 |
| `skills/` | Agent Skills 相关 Markdown |
| `agent/` | Agent 相关 Markdown |
| `i18n/` | 英文等翻译（若有） |
| `case/` | 案例相关 Markdown |

## 权威来源

- **在线阅读与发布以官网为准**：https://ieasyclick.com  
- **编辑源**通常在站点仓库 `newecdocs`；本仓用于公开浏览、检索与协作阅读。  
- 文内部分相对链接（如 `/docs/...`）在 GitHub 上可能无法跳转，请到官网打开对应路径。

## 同步说明

从 `newecdocs` 仅复制 `*.md`，不包含：

- `*.mdx`
- `src/`（React 页面与组件）
- `static/`、`build/`、`node_modules/`
- `internal/`（内部材料）
